# 🛡️ 타워 디펜스(가변형 미로 & 월드맵 캠페인) 기획서 (v1.5)

---

## 📌 1. 핵심 컨셉 (Core Concept)

- **장르:** 가변형 미로 설계 타워 디펜스 (Tower Defense)
- **핵심 슬로건:** *"길이 곧 리스크이자 리턴이 되는 타워 디펜스"*
- **핵심 특징:**
  1. 적과 아군이 완벽히 동일한 길찾기 AI를 공유하는 미로 설계
  2. 수동 조작을 배제하고 오직 **건설 및 사전 설계(Planning)**로 동선을 제어
    3. 월드맵의 5개 맵을 순환하며, 이전에 지은 방어선을 보강해야만 더 센 적을 막는 **캠페인 루프**

## 🎮 2. 핵심 메카닉 & 시스템 규칙

### ① 통합 길찾기 (Shared Pathfinding)
- **동일 AI 노드 공유:** 적(Enemy)과 아군(Ally)은 완벽히 동일한 A* Navigation Path를 공유함.
- **길이의 딜레마 (Risk & Return):**
  - **긴 미로:** 적이 타워 화망에 오래 노출되어 **방어력 상승** $\leftrightarrow$ 아군의 이동 시간이 길어져 **보상 수급 속도 저하**.
  - **짧은 미로:** 적의 진격이 빨라져 **방어 위험성 증가** $\leftrightarrow$ 아군이 본진에 빠르게 도착하여 **스노우볼링 가능**.

### ② 페이즈 분리 & 보상 메카닉
- 게임은 `Enemy Phase`와 `Ally Phase`가 번갈아 진행되는 타임라인 구조.
- 각 페이즈는 유닛 한 명이 아니라 **여러 유닛**이 간격을 두고 Start에서 등장한다.
- `Ally Phase`에 스폰된 아군 수송 유닛이 미로를 지나 본진(Base)에 안전하게 도착해야만 그 아군 분 골드(자원) 보상을 획득.
- 미로가 너무 길어 제한 시간 내에 들어오지 못했거나, 뒤따라 나오는 `Enemy Phase`의 적에게 꼬리가 잡히면 보상 소멸.

### ③ 자유로운 건설 규칙 (시스템적 차단 없음)
- 플레이어는 미로를 완전히 막아버리는 타워 건설도 **시스템 제약 없이 자유롭게 가능**.
- **결과 수용 (자업자득):**
  - 길을 완전히 막으면 **적도 본진으로 못 들어오지만, 아군 역시 본진에 들어가지 못함.**
  - 아군이 본진에 들어가지 못하면 **그 아군 분 골드/자원 보상을 전혀 받지 못해** 경제 스노우볼이 깨짐.
  - (선택 사항) 길이가 완전히 막혔을 때의 적 동작: 가장 가까운 타워나 벽을 부수며 직진하거나 길목에 대기.

### ④ 엔드콘텐츠: 월드맵 캠페인 루프 (허무함 방지)
- **월드맵:** 서로 다른 게임 맵 5개가 월드맵에 놓여 있다.
- **1사이클 (스테이지 1–5):** 스테이지 1은 맵 1, 스테이지 2는 맵 2, … 스테이지 5는 맵 5. 맵마다 지형이 다르고, 앞에서 클리어해야 다음 맵이 열린다.
- **2사이클부터 (스테이지 6–):** 다시 맵 1로 돌아온다. **그 맵에 이전에 지은 타워가 그대로** 남아 있다. 스테이지 7은 맵 2 + 그 맵의 기존 타워, 같은 식으로 5개 맵을 반복한다.
- **보강 강제:** 돌아온 판의 적은 이전 사이클보다 강하다. 기존 배치만으로는 버티기 어려워, 타워를 더 짓거나 업그레이드해야 한다.
- **패배 페널티:** 스테이지에서 Game Over가 나면 그 맵의 타워 약 절반이 파괴되고, 남은 타워는 체력이 10%~30%로 깎인 채로 남는다. 다른 맵의 타워는 그대로다.

## 📖 도메인 용어

같은 한글이 다른 뜻을 가리키지 않게, 아래만 공식 용어로 쓴다.  
개발 가이드의 `Phase 1` / `Step 5-4`는 **구현 작업 단위**이며, 게임의 페이즈·스테이지와 무관하다.

### 자주 헷갈리는 짝

| 용어 | 뜻 | 아닌 것 |
|---|---|---|
| **맵** | 월드맵에 있는 전장 5개. id는 1–5로 고정 (평원·협곡·해안·고원·습지). | 스테이지 번호. 맵 6은 없다. |
| **스테이지** | 캠페인 진행 번호 `1, 2, 3…` (상한 없음). 적 구성·시작 골드의 기준. | 맵. HUD의 웨이브. |
| **사이클** | 맵 5개를 한 바퀴. 스테이지 1–5 = 1사이클, 6–10 = 2사이클. | 페이즈. 한 배틀 안의 웨이브. |
| **페이즈** | 배틀 안의 시간대. `Enemy Phase` ↔ `Ally Phase`가 번갈아 돈다. | 개발 가이드의 Phase 1, 2… |
| **웨이브** | 한 배틀 안의 적 공세 횟수. HUD `웨이브 1 / 3`. | 스테이지. 웨이브 에디터의 행. |
| **버스트** | 한 Enemy Phase 안에서 줄지어 나오는 적 묶음. 묶음 사이에 쉬는 시간이 있다. | 웨이브. 스테이지. |

**대응 예:** 스테이지 1 = 맵 1(평원) 첫 방문. 스테이지 6 = **같은 맵 1**을 두 번째 도는 것(기존 타워 유지). 시작 골드는 맵이 아니라 스테이지 번호를 따른다.

### 공간

- **월드맵:** 배틀 전에 5개 맵을 고르는 화면. 지금 몇 스테이지인지, 어떤 맵이 열렸는지가 보인다.
- **배틀:** 고른 맵에서 한 스테이지를 플레이하는 전투. 그리드·유닛·골드가 여기서 움직인다.
- **그리드 / 타일:** 배틀 전장의 칸 격자. 맵마다 가로·세로 칸 수와 Start/Base 위치가 다르다.
- **Start:** 적·아군이 등장하는 칸. 타워를 지을 수 없다.
- **Base (본진):** 유닛의 도착점. 적이 들어가면 본진 HP가 줄고, 아군이 들어가면 골드가 는다. 타워를 지을 수 없다.
- **경로:** Start에서 Base까지 A*가 고른 길. 적과 아군이 **같은 경로**를 쓴다.
- **방해물:** 맵에 고정된 돌·나무. 타워가 아니다. 클릭해서 지우거나 그 칸에 지을 수 없고, 경로는 피해 간다. HP가 0이면 칸이 빈다.
- **타워:** 플레이어가 골드로 짓는 칸 점유물. 종류는 궁수·기사·대포·마법사·벽·연구. 기사는 인접 칸만 때리고, 대포는 범위 공격이다. 완성 전에 이미 길을 막고, 끝난 뒤에만 공격한다(벽·연구는 공격하지 않음). 웨이브가 끝나면 남은 타워는 체력이 조금 회복되고, **벽은 더 많이** 회복된다.
- **벽:** 공격이 없는 타워 종류. 같은 레벨 공격 타워보다 체력이 높아 길을 막는 용도. 자연 방해물(돌·나무)과는 다르다.
- **연구 타워:** 공격이 없는 타워. 배틀 중 주기적으로 **연구 포인트**를 만든다.
- **연구 포인트:** 연구 타워가 만드는 재화. 골드와 다르며, 타워 건설에는 쓰지 않는다.
- **연구 트리:** 월드맵(배틀 밖)에서 여는 메뉴. 연구 포인트로 고른 버프는 **모든 맵에 공통**으로 적용된다.

### 전투 흐름

- **유닛:** 그리드를 걷는 개체. **적**과 **아군**으로만 나뉜다.
- **적:** Enemy Phase에 Start에서 나온다. Base에 들어가면 본진 HP를 깎는다. 길이 없으면 타워·방해물을 부순다. 돌파형은 길이 있어도 곧게 가며 타워를 부순다. 매복형은 화망 밖에 숨었다가 아군 수송을 노린다.
- **아군:** Ally Phase에 Start에서 나오는 수송 유닛. **짐꾼·전령·행상·상인**이 번갈아 나오며, 종류마다 Base에 넣을 때 주는 골드가 다르다. 타워를 부수지 않는다. 적에게 잡히거나 시간에 쫓기면 그 분 보상은 없다.
- **골드:** 타워 건설·업그레이드 비용. 배틀이 끝나면 들고 나가지 않는다(맵의 타워만 남는다).
- **시작 골드:** 그 스테이지 배틀에 들어올 때 받는 골드. 스테이지 번호가 클수록 많다. 같은 맵이어도 스테이지 1과 6은 다르다.
- **아군 보상:** 아군 1명이 Base에 도착할 때 들어오는 골드. 짐꾼 10, 전령 15, 행상 20, 상인 30. 시작 골드만으로 맵을 다 채울 수는 없다.
- **본진 HP:** Base가 적에게 맞을 때마다 줄어든다. 0이면 Game Over.
- **Victory / Game Over:** 한 스테이지 배틀의 승패. 마지막 웨이브의 적이 **맵에서 전부 사라진 뒤** 본진이 살아 있으면 Victory(다음 스테이지 해금). 타이머만 끝나고 적이 남아 있으면 클리어되지 않는다. HP 0이면 Game Over. Game Over면 그 맵 타워의 약 절반이 파괴되고, 남은 타워는 체력이 10%~30%로 깎인 채 유지된다.
- **배속:** 일시정지 / 1배속 / 2배속 / 3배속. 건설은 일시정지 중에도 된다.

한 배틀의 큰 흐름은 `적 페이즈 → 아군 페이즈`를 반복하고, 마지막은 적 페이즈로 끝난다. HUD 웨이브가 올라가는 단위가 이 적 공세다.

### 데이터·에디터

- **적 정의:** 적 에디터/`enemies.json`의 한 줄. id·이름·스프라이트·HP·색(hue)·행동 유형. 웨이브는 이 id를 가리킨다.
- **스프라이트 종류:** 비스트·기병·늑대·슬라임·고블린. 같은 스프라이트도 HP·색이 다른 적 정의가 될 수 있다.
- **행동 유형:** 적이 길을 다루는 방식. **일반**은 A* 경로를 따라 우회하고, **돌파형**은 본진 쪽으로 곧게 가며 그 직선에 있는 타워를 부순다. **매복형**은 타워 사거리 밖 칸에 숨었다가 Ally Phase의 아군 수송을 공격한다.
- **웨이브 테이블:** `waves.json`. **스테이지 번호마다** 적 페이즈 시간, 아군 수, 버스트(적 묶음)를 적어 둔다. 각 적은 이전 적 출현 후 몇 초 뒤에 출발하는 지연을 가진다. 웨이브 에디터의 “스테이지 N”은 캠페인 스테이지 N과 **같은 번호**다.
- **웨이브 예고:** 적 웨이브가 시작될 때 이번 공세에 어떤 적이 나오는지 보여주는 표출. 여기에 **처음 나온 유형**은 도감에서 열린다.
- **도감:** 적 목록 메뉴. 처음에는 모두 실루엣만 보이고, 웨이브 예고에 처음 등장한 적부터 모습과 특징이 열린다.

### Phase 1. 기본 그리드 및 맵 시스템

- [x] **Step 1-1. 그리드 맵 그리기:** 화면에 $N \times M$ 크기의 기본 Grid 레이아웃 생성
  - [x] 게임을 실행하면 배틀 화면에 타일들이 격자로 보인다
  - [x] 가로·세로 칸 수를 눈으로 셀 수 있다 (칸 경계가 분명하다)
  - [x] 맵 전체가 한 화면에 들어오며, 타일이 화면 밖으로 잘려 보이지 않는다

- [x] **Step 1-2. 시작점과 본진 설정:** 맵 좌측 'Start', 우측 'Base' 타일 지정
  - [x] 맵 **왼쪽**에 Start 타일이 있고, 빈 칸과 구별된다 (라벨 또는 색)
  - [x] 맵 **오른쪽**에 Base 타일이 있고, Start·빈 칸과 구별된다
  - [x] 새로고침해도 Start / Base 위치가 바뀌지 않는다

- [x] **Step 1-3. 타워 건설 인터랙션:** 마우스 클릭으로 타일 위치에 자유롭게 타워 건설/취소
  - [x] 빈 타일을 클릭하면 그 칸에 타워가 생긴다
  - [x] 타워가 있는 칸을 다시 클릭하면 타워가 사라진다 (건설 취소)
  - [x] Start / Base 칸을 클릭해도 타워가 생기지 않는다
  - [x] 길을 막을 위치에도 타워가 들어간다 (건설이 거부되지 않는다)

### Phase 2. A* 통합 길찾기 & 경로 변경

- [x] **Step 2-1. 기본 A* 길찾기:** Start에서 Base까지의 최단 경로 계산 노드 구축
  - [x] 타워가 없을 때 Start에서 Base까지 **이어진 경로**가 화면에 표시된다
  - [x] 그 경로는 Start에서 시작해 Base에서 끝난다
  - [x] 빈 맵에서는 크게 돌아가지 않고, 왼쪽에서 오른쪽으로 가는 짧은 길로 보인다

- [x] **Step 2-2. 타워 건설 시 실시간 경로 재계산 (Path Refreshed):**
  - [x] 경로가 지나던 칸에 타워를 지으면, 경로가 **그 칸을 피해** 다시 그려진다
  - [x] 그 타워를 지우면, 경로가 다시 짧아진(또는 원래) 길로 돌아온다
  - [x] Start↔Base를 완전히 막히게 타워를 채워도 **건설은 된다**
  - [x] 그때 경로 선이 사라지고, 길이 없다는 상태가 화면에 드러난다 (빈 경로 / 안내 문구 등)

### Phase 3. 유닛 및 페이즈 제어

- [x] **Step 3-1. 유닛 이동 메카닉:** A* 경로를 따라 이동하는 기본 유닛 생성 (경로가 없으면 입구에서 대기/방황)
  - [x] 유닛이 Start에서 나타나 표시된 경로를 따라 Base 쪽으로 걷는다
  - [x] 타워로 길을 바꾸면, 이미 나온 유닛도 **새 경로**를 따라간다 (벽으로 파고들지 않는다)
  - [x] 길을 완전히 막으면 유닛이 Base에 도착하지 않고, **입구 쪽에서 대기하거나 헤맨다**
  - [x] 길을 다시 열면 그 유닛이 경로를 타고 이동을 재개한다

- [x] **Step 3-2. 봉쇄 시 벽 파괴:** 경로가 없으면 가장 가까운 타워를 부수고 길을 연다
  - [x] 길을 완전히 막으면 유닛이 Base로 통과하지 못하고, **막힌 길목의 타워를 때리기 시작한다**
  - [x] 맞는 타워의 HP가 줄어드는 것이 보인다
  - [x] HP가 0이면 그 타워가 사라지고, 경로가 다시 그려진다
  - [x] 타워가 무너져 길이 열리면, 그 유닛이 경로를 타고 Base 쪽으로 다시 걷는다

- [x] **Step 3-3. 페이즈 전환 타이머:** `Enemy Phase` ↔ `Ally Phase` 전환 상태 머신 및 UI
  - [x] HUD에 지금이 `Enemy Phase`인지 `Ally Phase`인지 보인다
  - [x] 남은 시간이 줄어드는 것이 보인다
  - [x] 시간이 0이 되면 페이즈가 반대쪽으로 바뀌고, 타이머가 다시 돈다
  - [x] 페이즈가 바뀌는 동안 맵·타워가 리셋되지 않는다

- [x] **Step 3-3a. 타임 컨트롤러:** 일시정지 / 1배속 / 2배속 / 3배속
  - [x] HUD에서 일시정지·배속을 고를 수 있다
  - [x] 일시정지면 유닛과 페이즈 타이머가 멈춘다
  - [x] 2배속·3배속이면 1배속보다 빠르게 진행된다
  - [x] 일시정지 중에도 타워 건설/취소는 된다

- [x] **Step 3-4. 아군 보상 및 봉쇄 처리 메카닉:**
  - [x] `Ally Phase`에 아군이 Start에서 나온다
  - [x] 아군이 Base에 들어가면 **골드가 늘어난다** (도착 전에 골드가 먼저 오르지 않는다)
  - [x] 길을 막아 아군이 Base에 못 들어가면, 아군은 **타워를 부수지 않고** 입구에서 대기하며 그 라운드 **골드가 오르지 않는다**
  - [x] 제한 시간이 끝나거나 페이즈가 넘어가면, 아직 맵에 남은 아군은 사라지고 그 유닛 분 골드도 없다

### Phase 4. 전투 및 타임어택

- [x] **Step 4-1. 적 유닛 & 본진 데미지:** 적 스폰 → 본진 도착 시 HP 차감
  - [x] `Enemy Phase`에 적이 Start에서 나와 경로를 따라 Base로 간다
  - [x] 적이 Base에 들어가면 **본진 HP가 줄어든다**
  - [x] 길을 완전히 막으면 적은 Step 3-2처럼 **타워를 부수며 길을 열고**, 그 동안 본진은 안 맞는다
  - [x] 길이 열린 뒤 적이 Base에 들어가면 그때 본진 HP가 줄어든다

- [x] **Step 4-2. 타워 공격 로직:** 사거리 내 적 탐지 및 데미지 처리
  - [x] 적이 타워 근처를 지나가면 타워가 그 적을 공격하는 것이 보인다
  - [x] 공격받은 적의 HP가 줄고, HP가 0이면 적이 사라진다
  - [x] 사거리 밖 적은 맞지 않는다
  - [x] 아군은 타워에게 맞지 않는다

- [x] **Step 4-3. 페이즈 오버랩 딜레마:** 아군이 다 들어오기 전 적 페이즈가 시작되는 타임어택 메카닉 완성
  - [x] 아군이 아직 맵에 남아 있는데 `Enemy Phase`가 시작될 수 있다 (아군이 전부 들어온 뒤에만 바뀌지 않는다)
  - [x] 늦게 들어온 아군이 Base에 도착하면 그때까지는 골드가 들어온다
  - [x] 남은 아군이 적에게 잡히거나 시간 안에 못 들어오면, 그 아군 분 보상은 없다
  - [x] 미로를 길게 만들수록 아군이 시간에 쫓기는 것이 플레이로 느껴진다

- [x] **Step 4-4. 웨이브 스폰:** 한 페이즈에 유닛이 여럿 나와 맵에 동시에 존재
  - [x] `Enemy Phase`가 시작되면 적이 Start에서 **여러 명** 나온다 (한 명만 나와서 끝나면 안 된다)
  - [x] 적들은 한 칸에 겹쳐 나오지 않고, **간격을 두고** 줄지어 나온다
  - [x] 동시에 맵 위에 적이 둘 이상 보일 수 있다
  - [x] 본진에 도착한 적마다 본진 HP가 줄어든다
  - [x] `Ally Phase`에도 아군이 여러 명 나와, 도착한 아군만큼 골드가 들어온다

### Phase 5. 게임 루프 & 월드맵 캠페인

- [x] **Step 5-1. 자원 & 건설 비용 시스템:** 종류 선택 팝업 → 건설 애니메이션 → 완성. 아군이 가져온 골드로 구매/업그레이드
  - [x] 빈 칸을 클릭하면 타워가 바로 생기지 않고, **타워 종류를 고르는 팝업**이 뜬다
  - [x] 팝업에서 종류가 서로 구별되고, 하나를 고를 수 있다
  - [x] 종류를 고르지 않고 팝업을 닫으면 그 칸은 비어 있다
  - [x] 종류를 고르면 그 칸에 **건설 중**이 보이고, 애니메이션이 끝난 뒤에야 타워가 완성된다 (완성 전과 후가 구별된다)
  - [x] 종류를 고른 순간부터 그 칸은 길을 막는다. 완성되기 전에는 적을 공격하지 않는다
  - [x] 타워를 지으면(종류를 고르면) 골드가 비용만큼 줄어든다
  - [x] 골드가 부족하면 팝업에서 고르거나 업그레이드해도 건설이 되지 않고, 이유가 보인다
  - [x] 기존 타워를 업그레이드하면 골드가 줄고, 그 타워가 더 강해진 것이 보인다 (사거리·데미지 등)
  - [x] 아군이 Base에 골드를 가져온 뒤에야 더 지을 수 있게 된다 (시작 골드만으로 무한 건설이 아니다)

- [x] **Step 5-2. 승리/패배 조건:** HP 0 이하 시 Game Over, 최종 웨이브 방어 시 Victory
  - [x] 본진 HP가 0이 되면 전투가 멈추고 Game Over가 보인다
  - [x] Game Over 이후에는 적·아군이 계속 나오지 않는다
  - [x] 마지막 웨이브까지 본진이 살아 있으면 Victory가 보인다
  - [x] 같은 조건으로 다시 플레이하면 승/패가 똑같이 갈린다 (HP 0이면 항상 패배, 막으면 승리)

- [x] **Step 5-3. 월드맵:** 서로 다른 게임 맵 5개가 놓인 월드맵에서 맵을 고른다
  - [x] 배틀 전에 **월드맵 화면**이 보인다 (또는 배틀에서 월드맵으로 나갈 수 있다)
  - [x] 월드맵에 **게임 맵이 5개** 보이고, 서로 다른 맵으로 구별된다
  - [x] 맵을 고르면 그 맵의 배틀 화면으로 들어간다 (Start/Base·지형이 맵마다 다르다)
  - [x] 배틀에서 월드맵으로 돌아오면, 고른 맵들이 그대로 남아 있다

- [x] **Step 5-3a. 맵 고정 자연 방해물:** 각 게임 맵에 돌·나무 같은 방해물이 정해진 칸에 있다. HP는 1레벨 타워보다 높다
  - [x] 각 게임 맵 배틀에 들어가면, 타워가 아닌 **돌·나무 같은 자연 방해물**이 칸에 보인다 (빈 칸·타워·Start·Base와 구별된다)
  - [x] 같은 맵은 새로고침하거나 다시 들어가도 **위치·종류가 같다** (랜덤으로 바뀌지 않는다)
  - [x] 다른 맵으로 바꾸면 방해물 배치가 **달라서** 맵이 구별된다
  - [x] 방해물 칸에는 타워를 지을 수 없고, 타워처럼 클릭해서 지울 수도 없다
  - [x] 경로는 방해물 칸을 **피해** 간다
  - [x] 방해물의 HP가 보이고, **1레벨 타워 HP보다 높다** (길을 막아 적이 때리면 1레벨 타워보다 오래 버틴다)
  - [x] HP가 0이면 그 칸이 비고, 경로가 다시 그려진다

- [x] **Step 5-4. 스테이지 1–5:** 5개 맵이 스테이지 1부터 5까지 하나씩 대응한다
  - [x] 스테이지 1은 첫 번째 맵, 2는 두 번째, … 5는 다섯 번째 맵이다
  - [x] 앞 스테이지를 Victory해야 다음 맵이 열린다 (처음부터 5개를 다 고를 수 없다)
  - [x] 월드맵에 지금 몇 스테이지인지, 어떤 맵이 클리어됐는지 보인다
  - [x] 스테이지가 올라갈수록 적이 더 많다/세다 (1과 5를 플레이하면 차이가 느껴진다)

- [x] **Step 5-5. 캠페인 루프 & 타워 유지:** 스테이지 6부터 첫 맵으로 돌아오고, 이전에 지은 타워가 남아 있다
  - [x] 스테이지 5를 클리어하면 스테이지 6이 열린다
  - [x] 스테이지 6은 **첫 번째 게임 맵**이다 (새 맵이 아니다)
  - [x] 스테이지 1에서 지은 타워가 **그대로** 깔려 있다 (앱을 다시 켜도 유지된다)
  - [x] 스테이지 7은 두 번째 맵 + 그 맵의 기존 타워, 같은 식으로 5개 맵을 다시 돈다

- [x] **Step 5-6. 루프 난이도 & 보강:** 돌아온 판은 적이 더 세서, 기존 배치만으로는 버티기 어렵다
  - [x] 같은 맵의 이전 사이클보다 적이 강하다 (HP·수·속도 중 분명한 차이)
  - [x] 기존 타워만 두고 아무것도 안 하면 막기 어렵다
  - [x] 타워를 추가하거나 업그레이드하면 이번 사이클을 막을 수 있다
  - [x] 막으면 다음 루프 스테이지로, 본진이 무너지면 Game Over다

### Phase 6. 플레이 폴리스 & 적 변주

- [x] **Step 6-1. 전투 비주얼 다듬기:** 화살 크기, 궁수 위치, 상단 HUD, 타워 HP 게이지
  - [x] 화살 투사체가 이전보다 작고, 타일·유닛을 가리지 않는다
  - [x] 궁수 타워의 궁수가 성벽 위에 서 있고, 발이 타일 아래로 삐져나오지 않는다
  - [x] 상단 HUD가 세로로 길게 늘어지지 않고, 페이즈·골드·HP·배속이 한눈에 들어온다
  - [x] 타워 HP가 가득이면 게이지바가 보이지 않고, 데미지를 받은 뒤에만 보인다

- [x] **Step 6-2. 스테이지별 시작 골드:** 스테이지가 올라갈수록 베이스 골드가 늘어난다
  - [x] 스테이지 1의 시작 골드와 뒤 스테이지(3 이후)의 시작 골드가 다르다
  - [x] 뒤 스테이지가 앞 스테이지보다 시작 골드가 많다
  - [x] 같은 스테이지를 다시 들어가면 시작 골드는 같다
  - [x] 시작 골드만으로 무한 건설이 되지 않는다 (아군 보상이 여전히 필요하다)

- [x] **Step 6-3. 웨이브 여유 시간 축소:** 적/아군 웨이브 끝의 빈 시간을 줄인다
  - [x] 적 웨이브에서 마지막 적이 나온 뒤, 다음 페이즈까지 남는 빈 시간이 이전보다 짧다
  - [x] 아군 웨이브에서도 마지막 아군이 나온 뒤 남는 빈 시간이 짧다
  - [x] 일시정지·배속은 그대로 된다
  - [x] 아군이 아직 맵에 남아 있는데 적 페이즈가 시작될 수 있다 (타임어택이 유지된다)

- [x] **Step 6-4. 돌파형 적:** 우회하지 않고 직선 거리의 타워를 부수며 직진
  - [x] 돌파형 적이 웨이브에 섞여 나온다 (일반 적과 구별된다)
  - [x] 길이 열려 있어도, 돌파형 적은 S미로를 따라가지 않고 본진 쪽으로 더 곧게 간다
  - [x] 그 직선에 타워가 있으면 타워를 때리고, HP가 0이면 타워가 사라진다
  - [x] 일반 적은 기존처럼 경로를 따라 우회한다
  - [x] 궁수 타워로만 긴 S루트를 만들면, 돌파형 적 때문에 막기 어려워진다

- [x] **Step 6-5. 매복형 적:** 화망 밖 칸에 숨어 있다가 아군 보상 수송을 노린다
  - [x] 매복형 적이 웨이브에 섞여 나온다 (일반 적·돌파형과 구별된다)
  - [x] 매복형 적은 타워 사거리 밖(공격받지 않는 칸)으로 가서 대기한다
  - [x] Enemy Phase 동안에는 본진으로 돌격하지 않고 숨어 있는 것이 보인다
  - [x] Ally Phase에 아군이 보상을 들고 지나가면, 매복형 적이 그 아군을 공격한다
  - [x] 사각 지대를 비워 두면 아군이 잡히고 그 분 골드가 없다
  - [x] 화망이 사각을 덮으면 매복형 적이 숨지 못하거나 버티지 못한다

- [x] **Step 6-6. 랜드마크 & 희소 피드백:** Start/Base 그래픽, 누수·보상처럼 드문 이벤트만 소리로 (에셋 수집 후)
  - [x] Start 칸이 전용 그래픽으로 빈 칸·Base와 구별된다
  - [x] Base 칸이 전용 그래픽으로 Start·빈 칸과 구별된다
  - [x] 적이 Base에 들어가면 본진이 한 번 흔들리거나 번쩍이고, **짧은 경고음이 한 번** 난다 (HP가 줄어드는 동안 계속 울리지 않는다)
  - [x] 아군이 Base에 들어가면 골드가 들어온 것이 보이고, **보상음이 한 번** 난다 (누수음과 구별된다)
  - [x] 아군이 적에게 잡히거나 시간 안에 못 들어오면 **짧은 손실음이 한 번** 난다 (보상음·누수음과 구별된다)
  - [x] 타워가 적에게 부서져 사라질 때 짧은 붕괴음이 난다
  - [x] 적이 맞거나 죽을 때는 **효과음을 내지 않는다** (투사체·사망 애니메이션으로만 보인다)
  - [x] 2배속·3배속·적이 여럿이어도 소리가 겹쳐 소음이 되지 않는다

### Phase 7. 타워 편의 · 역할 변주 · 패배 페널티

- [x] **Step 7-1. 타워 선택 사거리 & 축약 메뉴:** 타워를 고르면 사거리가 맵에 보이고, 첫 화면은 업그레이드·상세만 있는 작은 메뉴다
  - [x] 완성된 공격 타워를 클릭하면, 그 타워 기준으로 **사거리 범위**가 맵에 표시된다
  - [x] 벽처럼 공격이 없는 타워는 사거리 원이 나오지 않는다
  - [x] 다른 타워를 고르면 사거리가 그 타워 기준으로 바뀌고, 메뉴를 닫으면 사거리 표시가 사라진다
  - [x] 타워를 처음 클릭했을 때 팝업은 작고, 맵의 사거리를 가리지 않는다 (스펙 숫자가 한가득 보이지 않는다)
  - [x] 그 작은 메뉴에 **업그레이드**와 **상세** 버튼이 있다
  - [x] 상세를 누르면 그때 레벨·체력·사거리·공격 같은 스펙이 보인다
  - [x] 업그레이드는 기존처럼 골드가 줄고 타워가 강해진다

- [x] **Step 7-2. 범위딜·근접 타워:** 여러 적을 한 번에 때리는 타워와, 바로 옆만 때리는 타워
  - [x] 건설 팝업에서 범위 공격 타워와 근접 타워를 고를 수 있고, 궁수·벽과 구별된다
  - [x] 범위 공격 타워가 적을 때리면, **한 발에 근처 적 둘 이상**이 맞을 수 있다
  - [x] 근접 타워는 **바로 옆 칸**(인접)의 적만 때리고, 그 밖 칸의 적은 맞지 않는다
  - [x] 궁수는 기존처럼 한 명만 때리며, 근접보다 먼 적도 맞는다
  - [x] 골드가 부족하면 기존처럼 건설되지 않는다

- [x] **Step 7-3. 웨이브 에디터 적 팔레트 그래픽:** 팔레트에서 적의 모습이 보인다
  - [x] 웨이브 에디터를 열면 적 팔레트에 **이름만이 아니라 그래픽**이 보인다
  - [x] 스프라이트 종류가 다르면 팔레트 그림도 다르게 보인다
  - [x] 같은 스프라이트라도 색(hue)이 다르면 팔레트에서도 색이 다르게 보인다
  - [x] 팔레트에서 고른 적을 버스트에 넣으면, 그 적이 목록에 추가된다

- [ ] **Step 7-4. 몬스터별 출현 지연:** 적마다 이전 적 출현 후 몇 초 뒤에 출발할지 정한다
  - [ ] 웨이브 에디터에서 버스트 공통 간격만 쓰지 않고, **적 한 마리마다** 이전 적 다음 몇 초 뒤인지 숫자를 넣을 수 있다
  - [ ] 첫 적은 지연 0이어도 되고, 뒤 적은 더 긴 지연을 줄 수 있다
  - [ ] 저장한 뒤 그 스테이지를 플레이하면, 적들이 **그 지연대로** 간격을 두고 Start에서 나온다
  - [ ] 지연을 전부 짧게 하면 적이 거의 붙어서 나오고, 길게 하면 드문드문 나온다
  - [ ] 버스트가 끝난 뒤 다음 버스트까지의 휴식은 기존처럼 따로 있다

- [ ] **Step 7-5. 패배 시 타워 손실:** Game Over면 그 맵 타워의 절반은 사라지고, 나머지는 체력이 크게 깎인다
  - [ ] 스테이지에서 본진 HP가 0이 되면 Game Over가 보인다 (전투는 기존처럼 멈춘다)
  - [ ] 월드맵으로 나온 뒤 **방금 패배한 맵**은 바로 다시 들어가지 못하고, 지원군이 그 맵을 다시 탈환할 때까지 **일정 시간**이 걸린다. 탈환 후 다시 들어가면 그 맵에 있던 타워의 **약 절반이 없다**
  - [ ] 남아 있는 타워는 체력이 **최대의 10%~30%** 사이고, HP 게이지가 보인다
  - [ ] 다른 맵의 타워는 그대로다
  - [ ] 앱을 다시 켜도 그 맵의 파괴·체력 감소가 유지된다
  - [ ] 타워가 없던 맵에서 지면, 타워 관련 변화 없이 Game Over만 난다

### Phase 8. 건설 UI · 도감 · 웨이브 예고

`docs/review/20260918.md` 편의성. 건설 팝업을 그림으로 읽고, 적이 누구인지 미리 보게 한다.

- [ ] **Step 8-1. 건설 팝업 이미지 & 호버 스펙:** 종류를 고를 때 건물 그림이 보이고, 올리면 상세 스펙이 나온다
  - [ ] 빈 칸을 클릭해 건설 팝업을 열면, 각 종류에 **건물 이미지**가 보인다 (이름·숫자만 있는 칸이 아니다)
  - [ ] 종류가 다르면 그림도 다르게 보인다 (궁수·기사·대포·마법사·벽이 구별된다)
  - [ ] 종류 위에 마우스를 올리면 **상세 스펙**(비용·체력·사거리·공격 등)이 보인다
  - [ ] 마우스를 치우면 상세 스펙이 사라지고, 팝업만 봐서는 스펙 숫자가 한가득 보이지 않는다
  - [ ] 종류를 고르지 않고 닫으면 그 칸은 비어 있다
  - [ ] 종류를 고르면 기존처럼 골드가 줄고 건설이 시작된다

- [ ] **Step 8-2. 적 도감:** 적마다 특징을 볼 수 있는 도감. 처음에는 실루엣만 보인다
  - [ ] 월드맵 또는 HUD에서 **도감**을 열 수 있다
  - [ ] 도감에 적 목록이 있고, 처음에는 모두 **실루엣**만 보인다 (모습·이름이 처음부터 다 열린 상태가 아니다)
  - [ ] 아직 열리지 않은 적은 특징이 보이지 않는다
  - [ ] 열린 적을 고르면 그 적의 모습과 특징(행동 유형·대략적인 역할 등)이 보인다
  - [ ] 도감을 닫아도 배틀·월드맵 진행은 바뀌지 않는다

- [ ] **Step 8-3. 웨이브 예고 & 도감 해금:** 웨이브가 시작될 때 이번 적이 보이고, 처음 나온 유형은 도감에 열린다
  - [ ] 적 웨이브가 시작되면, 이번 공세에 **어떤 적이 나오는지** 화면에 잠시 보인다
  - [ ] 이미 나온 적과 **새로 나오는 유형**이 구별된다
  - [ ] 예고에 처음 나온 유형이 있으면, 도감에서 그 적의 실루엣이 풀리고 모습·특징이 보인다
  - [ ] 예고에 없던 적은 도감에서 실루엣으로 남아 있다
  - [ ] 예고가 끝난 뒤 기존처럼 적이 Start에서 나온다

### Phase 9. 수리 · 밸런스 · 연구

`docs/review/20260918.md` 밸런스와 웨이브 종료 수리. 벽은 더 튼튼하고, 클리어는 적 전멸, 대포는 범위, 연구는 맵 공통 버프다.

- [ ] **Step 9-1. 웨이브 종료 수리:** 웨이브가 끝나면 타워 체력이 조금 회복되고, 벽은 더 많이 회복된다
  - [ ] 적이 타워를 때려 HP가 깎인 뒤, 그 **웨이브가 끝나면** 타워 HP가 조금 회복된다
  - [ ] 일반 벽은 같은 상황에서 **공격 타워보다 더 많이** 회복된다
  - [ ] 이미 체력이 가득인 타워는 그대로다 (최대를 넘지 않는다)
  - [ ] 웨이브가 끝나기 전에는 이 수리로 HP가 오르지 않는다
  - [ ] 본진 HP는 이 수리로 회복되지 않는다

- [ ] **Step 9-2. 일반 벽 방어력 버프:** 벽이 같은 레벨 공격 타워보다 뚜렷하게 오래 버틴다
  - [ ] 1레벨 벽의 체력이 **같은 레벨 궁수보다 분명하게 높다**
  - [ ] 길을 막아 적이 벽을 때리게 하면, 같은 레벨 궁수를 막았을 때보다 벽이 오래 남는다
  - [ ] 벽은 기존처럼 공격하지 않는다
  - [ ] 벽 건설·업그레이드는 기존처럼 골드를 쓴다

- [ ] **Step 9-3. 적 전멸 클리어:** 마지막 웨이브가 끝나도 적이 남아 있으면 Victory가 아니다
  - [ ] 마지막 웨이브의 타이머가 끝나도, 맵에 적이 남아 있으면 Victory가 되지 않는다
  - [ ] 매복형 적도 남아 있으면 클리어되지 않는다
  - [ ] 맵의 적이 **전부 사라진 뒤**에야 Victory가 보인다
  - [ ] 본진 HP가 0이면 기존처럼 Game Over다
  - [ ] 앞 웨이브만 막은 상태에서는 마지막 웨이브 전에 Victory가 나지 않는다

- [ ] **Step 9-4. 대포 범위 공격:** 대포 한 발이 근처 적 여럿을 때린다
  - [ ] 건설 팝업에서 대포가 **범위 공격**으로 궁수·기사와 구별된다
  - [ ] 적이 붙어 있으면 대포 **한 발에 둘 이상**이 맞는다
  - [ ] 궁수는 기존처럼 한 명만 때린다
  - [ ] 그 발의 범위 밖·대포 사거리 밖 적은 맞지 않는다
  - [ ] 골드가 부족하면 기존처럼 대포가 건설되지 않는다

- [ ] **Step 9-5. 연구 타워 & 연구 트리:** 연구 타워가 연구 포인트를 만들고, 맵 밖에서 공통 버프를 고른다
  - [ ] 건설 팝업에서 **연구 타워**를 고를 수 있고, 궁수·기사·대포·마법사·벽과 구별된다
  - [ ] 연구 타워는 적을 공격하지 않고, 완성된 뒤 **연구 포인트가 시간에 따라 늘어난다**
  - [ ] 연구 타워가 없으면 연구 포인트가 오르지 않는다
  - [ ] 월드맵(배틀 밖)에서 **연구 트리** 메뉴를 열 수 있다
  - [ ] 연구 포인트로 버프를 고르면 포인트가 줄고, 그 버프가 **모든 맵**에 적용된다 (한 맵에서만 적용되지 않는다)
  - [ ] 앱을 다시 켜도 고른 버프와 남은 연구 포인트가 유지된다
  - [ ] 골드가 부족하면 연구 타워가 건설되지 않는다

### Phase 10. 전투 사운드

`docs/review/20260918.md` 에셋. Step 6-6의 희소 피드백(누수·보상·손실·붕괴)은 유지하고, 공격·사망음과 BGM을 더한다.

- [ ] **Step 10-1. 공격·사망 효과음:** 타워가 때릴 때와 적이 죽을 때 소리가 난다
  - [ ] 타워가 적을 공격하면 **공격 효과음**이 난다
  - [ ] 적의 HP가 0이 되어 사라질 때 **사망 효과음**이 난다
  - [ ] 공격음과 사망음이 서로 구별된다
  - [ ] 아군 보상음·누수음·붕괴음은 기존처럼 나고, 적 사망음과 뒤섞여 안 들리지 않는다
  - [ ] 2배속·3배속·적이 여럿이어도 소리가 겹쳐 듣기 힘든 소음이 되지 않는다

- [ ] **Step 10-2. 배틀 BGM:** 전투 중 배경음이 흐른다
  - [ ] 배틀에 들어가면 **BGM**이 들린다
  - [ ] 월드맵으로 나오면 그 배틀 BGM이 멈춘다
  - [ ] 한 배틀 안에서는 BGM이 갑자기 끊기지 않고 이어진다
  - [ ] 공격·사망·누수 같은 효과음이 나도 BGM이 깨지지 않는다
  - [ ] Victory / Game Over 화면에서도 소리가 깨지거나 겹쳐 소음이 되지 않는다
