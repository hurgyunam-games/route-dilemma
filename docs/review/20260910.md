
## 편의성
- 타워를 선택하면 해당 타워의 사거리가 나타났으면 좋겠음.
- 처음 타워를 한번 누를 때는 사거리를 볼 수 있게 팝업 메뉴를 최소화 했으면 좋겠음. 업그레이드 버튼과 상세 버튼을 두고 상세버튼을 누르면 해당 타워의 상세 스펙을 그 때 볼 수 있는 느낌으로

## 밸런스
- 범위딜을 넣는 타워라던가 근접 공격만 하는 타워가 있었으면 좋겠음.

## 웨이브 에디터
- 웨이브 에디터의 적 팔레트에도 적의 그래픽 이미지가 보였으면 좋겠음.
- 현재는 웨이브에 적 간격 수치를 공통으로 쓰는데 그냥 몬스터별로 이전 몬스터 출현 후 몇초 뒤에 출발할지를 설정할 수 있게 했으면 좋겠음.

## 게임 오버
- 특정 스테이지 패배시 해당 맵의 타워들의 50%는 아예 파괴. 나머지 50%는 체력 10%~30% 사이로 존재하게 하면 좋을 듯
