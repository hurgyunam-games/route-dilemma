## 그래픽
- 화살 투사체가 부자연스럽다. 크기를 좀 더 줄이던지 해야할 것 같다.
- 상단 HUD가 너무 세로로 길게 나열되어있다. 좀 더 예쁘게 다듬을 수 있으면 좋겠다.
- 궁수 타워의 궁수 Y좌표를 좀 더 위로 올렸으면 좋겠다. 지금 상태는 발이 밑으로 삐져나와있다.

## 밸런스
- 매 스테이지마다 똑같은 골드가 기본 베이스 골드로 가는 것 같은데 적들은 점점 강해지니 3스테이지쯤 가면 너무 힘들다. 스테이지가 올라갈 때마다 더 많은 베이스 골드를 줬으면 좋겠다.
- 단순히 궁수타워로 S루트만 만들면 게임이 너무 원활히 진행된다. 좀 더 유저로 하여금 전략적 선택이 요구되도록 만들면 재미있을 것 같다.
- 적의 패턴에 좀 더 다양한 변주를 주면 좋겠다. 

### 적의 패턴
- 우회하지 않고 직선 거리에 있는 타워를 부수며 나아가는 패턴을 가졌으면 좋겠다.
- 공격받지 않을 수 있는 공간을 찾아 숨어있다가 아군이 보상을 들고 들어올 때 공격한다.

## 편의성
- 적 웨이브, 아군 웨이브 끝에 시간이 남는다. 일시정지가 가능한 게임이기에 좀 더 타이트하게 해도 될 것 같다.
