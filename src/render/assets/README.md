# Local image assets

Raster image files in this folder are **not** part of the git repository (license). Clone/pull will not include them.

Place the following files here on your machine if you have the rights to use them:

- `floor.png`
- `tower.png` (1×6 idle sheet)
- `enemy-walk.png` (1×6 walk sheet)
- `enemy-attack.png` (1×6 attack sheet)

Without these files the app still runs, using solid-color placeholders.
