# Local image assets

Raster image files in this folder are **not** part of the git repository (license). Clone/pull will not include them.

Place the following files here on your machine if you have the rights to use them:

- `floor.png`
- `tower-build-1.png` … `tower-build-3.png` (1×4 construction stages, played in order)
- `tower-lv1.png` … `tower-lv5.png` (idle sheets; 1×4 for lv1, 1×6 for lv2–5)
- `tower-up2.png` … `tower-up5.png` (1×4 upgrade-to-level sheets)
- `cannon-build-1.png` … `cannon-build-3.png` (1×4 construction stages)
- `cannon-bases-wood.png` / `cannon-bases-stone.png` / `cannon-bases-keep.png` (1×4 level bases)
- `cannon-lv5.png` (1×6 top-level firing)
- `cannon-up2.png` … `cannon-up5.png` (1×4 upgrade-to-level sheets)
- `mage-lv1.png` … `mage-lv4.png` (1×4 idle; lv5 reuses lv4)
- `occupant-archer-idle.png` (1×4)
- `occupant-archer-attack.png` (1×6)
- `occupant-archer-preattack.png` (1×1)
- `occupant-cannon-idle.png` (1×6)
- `occupant-cannon-attack.png` (1×6)
- `occupant-cannon-preattack.png` (1×6)
- `occupant-mage-1-idle.png` / `occupant-mage-1-attack.png` (lv1)
- `occupant-mage-2-idle.png` / `occupant-mage-2-attack.png` (lv2)
- `occupant-mage-3-idle.png` / `occupant-mage-3-attack.png` (lv3+)
- `arrow-01.png` … `arrow-27.png` (archer projectile directions)
- `cannon-proj-01.png` … `cannon-proj-03.png` (cannon projectile by tower level)
- `mage-proj-01.png` … `mage-proj-03.png` (mage projectile by tower level)
- `enemy-walk.png` (1×6 walk sheet)
- `enemy-attack.png` (1×6 attack sheet)
- `obstacle-rock-1.png` … `obstacle-rock-3.png` (rock tiles)
- `obstacle-tree-1.png` (tall tree)
- `obstacle-bush-1.png` … `obstacle-bush-6.png` (tree-tile bushes)

Without these files the app still runs, using solid-color placeholders.
